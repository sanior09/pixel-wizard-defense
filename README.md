## 🎯 กติกาและวิธีเล่น

ผู้เล่นจะรับบทเป็น **พ่อมดผู้พิทักษ์บนกำแพงปราสาท** เพื่อยิงลูกบอลเวทมนตร์ใส่มอนสเตอร์ที่ตกลงมาจากท้องฟ้ายามค่ำคืนภายในเวลา **60 วินาที**

| เป้าหมาย | ประเภท | คะแนน |
| :--- | :--- | :---: |
| 🟢 สไลม์ • 🟣 ค้างคาว • 👻 ผี • 🐉 มังกรน้อย | มอนสเตอร์บุกปราสาท | **`+10`** |
| 🧚 นางฟ้า • 🐱 สัตว์เลี้ยงเวทมนตร์ | ฝ่ายมิตร *(ระวังอย่ายิงโดน!)* | **`-10`** |

### 🕹️ การควบคุมแสนง่าย
- **คอมพิวเตอร์:** เลื่อนเมาส์และคลิกตำแหน่งที่ต้องการยิง หรือใช้ปุ่ม `A` / `D` / ลูกศรซ้าย-ขวา ร่วมกับ `Spacebar`
- **มือถือ / แท็บเล็ต:** แตะตำแหน่งบนหน้าจอเพื่อเล็งยิงลูกบอลเวทมนตร์ได้ทันที หรือใช้ปุ่มบังคับ `◀` `▶` และ `✨ ยิง` ด้านล่าง

## ✨ ฟีเจอร์เด่นในเกม

- 🎨 **กราฟิก 2D Pixel Art Fantasy วาดด้วยโค้ด 100%:** ใช้ `Pixel Matrix` บน `Canvas 2D` วาดตัวละครแอนิเมชัน 2 เฟรม ฉากปราสาทเวทมนตร์ พระจันทร์ ดวงดาว หิ่งห้อย และเอฟเฟกต์ Particle
- 🔊 **ระบบเสียง 8-bit สังเคราะห์ในตัว:** สร้างเสียงร่ายเวท ยิงโดนมอนสเตอร์ เสียงเตือนฝ่ายมิตร และเสียงจบเกมผ่าน `Web Audio API` (เปิด/ปิดเสียงได้)
- ⏱️ **HUD เรียลไทม์ & จบเกมใน 60 วินาที:** แสดงคะแนน เวลาถอยหลัง สถิติสูงสุด (`localStorage`) พร้อมสรุปยศจอมเวทและปุ่ม **เริ่มเกม / เล่นใหม่**
- 📱 **Responsive Design:** ปรับขนาดหน้าจออัตโนมัติ รองรับทั้งหน้าจอคอมพิวเตอร์ แล็ปท็อป แท็บเล็ต และสมาร์ตโฟน

## 🛠️ เทคโนโลยีที่ใช้ (สิ่งที่น้องๆ จะได้เรียนรู้ในสาขา IT)

1. **HTML5 & CSS3:** การออกแบบหน้าเว็บแบบ Responsive กรอบสไตล์เกมพิกเซลเรโทร และการจัดวาง UI บนมือถือและเดสก์ท็อป
2. **JavaScript (ES6+) & Game Loop:** การคำนวณทิศทางการยิง การตรวจจับการชน (Collision Detection) และการใช้ `requestAnimationFrame`
3. **HTML5 Canvas 2D:** การเรนเดอร์สไปรต์ Pixel Art ด้วยตารางสีและภาพคมชัดแบบ Nearest-Neighbor (`imageSmoothingEnabled = false`)
4. **Web Audio API:** การสังเคราะห์คลื่นเสียงดิจิทัลสไตล์เกมอาร์เคด 8-bit บนเว็บเบราว์เซอร์
5. **Git, GitHub & Cloud Deployment:** การจัดการซอร์สโค้ดและการนำเว็บไซต์ขึ้นออนไลน์ผ่าน **Vercel**

## 📂 โครงสร้างไฟล์โปรเจกต์

```text
pixel-wizard-defense/
├── index.html   # โครงสร้างหน้าเว็บ, แถบคะแนน HUD และหน้าจอเริ่ม/จบเกม
├── style.css    # ตกแต่ง UI สไตล์ Fantasy Pixel Art และรองรับทุกขนาดหน้าจอ
├── sprites.js   # วาดตัวละคร Pixel Art (พ่อมด, มอนสเตอร์, นางฟ้า, สัตว์เลี้ยง)
├── audio.js     # ระบบสังเคราะห์เสียงเอฟเฟกต์ 8-bit ผ่าน Web Audio API
└── game.js      # ลูปเกม ฉากปราสาทเวทมนตร์ ระบบนับคะแนน ตัวจับเวลา 60 วินาที และการควบคุม
```
